# Aegis — Automated Red-Team Gauntlet — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, batch
> with per-phase commits). TDD for redteam core + harness. Author files via Bash heredocs
> (`cat > path <<'EOF' … EOF`) — Write/Edit are blocked by the bg-isolation guard once `.git`
> exists. Commit per phase via Bash with the Co-Authored-By trailer.

**Goal:** A public, portfolio-grade automated red-team gauntlet: an adaptive attacker agent
red-teams a target on harmless proxies (canary-extraction + prompt-injection), scored
deterministically; layered defenses measurably reduce attack-success. Two committed numbers:
adaptation-lift and defense-reduction.

**Architecture:** Reuse Quorum's kernel (`core/`: ModelClient seam, SQLite tracing,
orchestrator, pricing). New `redteam/` holds scenarios, techniques, the adaptive attacker,
target adapter, deterministic judge, defenses, and the gauntlet runner. `evals/` computes ASR
+ ablations + bootstrap CIs, dry-run by default from committed fixtures, cost-gated live run.
`ui/` is a static Next.js dashboard reading a committed JSON export.

**Tech Stack:** Python 3.10+ (stdlib + httpx + optional anthropic/openai), SQLite, pytest,
ruff, mypy. Next.js 15 + React + Tailwind v4 static export. DeepSeek via env keys.

---

## Responsible-red-teaming invariant (applies to EVERY task)
Canary + injection proxies ONLY. No real harmful content ever solicited or generated.
Success scoring is deterministic (exact string / sentinel match) — NO LLM-judge in the
success path. The LLM is only the attacker and the optional input-classifier defense.

## File structure (what each file owns)
- `core/*` — vendored Quorum kernel (adapt DeepSeek base-url env var only).
- `redteam/scenarios.py` — Scenario dataclass + 6 committed scenarios (3 canary, 3 injection)
  each carrying its deterministic success check kind.
- `redteam/techniques.py` — Technique dataclass + ~12 attack-template taxonomy.
- `redteam/judge.py` — deterministic success checker (canary substring; injection sentinel).
- `redteam/target.py` — TargetAdapter: wraps a ModelClient with a scenario's policy; runs a turn.
- `redteam/attacker.py` — adaptive attacker agent (turn 1 = single-turn baseline; ≤K turns).
- `redteam/defenses.py` — 3 stackable layers (prompt-hardening, input-classifier, output-scan).
- `redteam/gauntlet.py` — runner: iterate (scenario × technique × condition), trace each trial.
- `evals/metrics.py` — ASR matrices + ablations + bootstrap CIs (reuse grade.bootstrap_ci).
- `evals/run_gauntlet.py` — CLI: dry-run default, AEGIS_LIVE gate, cost estimate, cap, degraded guard.
- `evals/scenarios/` committed labeled scenarios; `evals/fixtures/` recorded responses;
  `evals/results/` committed ASR tables (json+md) + ui export.
- `ui/` — Next.js dashboard (hero, heatmap, ablation bars, attack log).
- `docs/writeup.md`, `docs/architecture.svg`. `tests/`. `.github/workflows/ci.yml`. `Makefile`.

## Phase 3 — defenses (TDD)

      PromptHardening (spotlighting/delimiter + untrusted-data framing, mutates target system);
